PUBLIC RELEASE STRUCTURE
========================

github_repo/
|
+-- README.md                      -> default GitHub landing page in English
+-- README.zh-CN.md                -> Chinese mirror page
+-- config.json                    -> placeholder runtime config
+-- config.example.json            -> copyable config template
+-- pyproject.toml                 -> package metadata
+-- requirements.txt               -> dependency list
|
+-- data/
|   |
|   +-- sample/
|   |   |
|   |   +-- abstracts_final_demo_first100.xlsx
|   |       -> random 100-row demo of the post-screening abstract table
|   |   +-- 09_factor_label_associations_semantic_merged_v2_demo_first100.csv
|   |       -> random 100-row demo of the Step 09 synonym file
|   |
|   +-- demo_resources/
|       |
|       +-- factor-subcategory.json
|       +-- country_continent_reference.csv
|       +-- umls_concepts_demo.csv
|       +-- guideline/{ATA 2015, NCCN 2023}/*.json
|
+-- prompt/
|   |
|   +-- en/                        -> English prompts used by default
|   +-- zh/                        -> Chinese prompt mirrors
|
+-- src/thca_risk_factor_toolkit/
|   |
|   +-- pipeline.py                -> end-to-end workflow
|   +-- structured_extraction.py   -> LLM title+abstract -> causal triplets
|   +-- deduplicate_title.py       -> title dedup
|   +-- count_thyroid_triplets.py  -> thyroid-related triplet filter
|   +-- classify_risk_factors.py   -> Level-3 classification
|   +-- factor_classifier.py       -> classification (LLM + rule fallback)
|   +-- group_synonyms.py          -> synonym factor map
|   +-- merge_age.py               -> Age consolidation
|   +-- factor_data.py             -> source triplet parsing
|   +-- factor_scores.py           -> composite evidence score
|   +-- guideline_analysis.py      -> guideline concordance
|   +-- evidence_quantification.py -> scoring + guideline entry
|   +-- umls_match.py              -> UMLS matching
|   +-- statistics.py              -> bibliometric tables
|   +-- ablation/                  -> clustering ablation
|
+-- scripts/
|   |
|   +-- install.sh
|   +-- run_demo.sh
|   +-- run_full.sh
|
+-- docs/

    +-- architecture.md
