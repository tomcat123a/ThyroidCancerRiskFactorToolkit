# Manuscript Table Mapping

This repository does not reproduce figures, but it does export table-ready data aligned with the manuscript themes described in `论文写作1-2.docx`.

## Covered Table Themes

1. Literature volume by publication period
   - `paper_year_basic_stats`

2. Study-type composition
   - `study_type_stats`

3. Continent-level factor counts by time bin
   - `continent_year_bin_long`
   - `continent_year_bin_pivot`

4. Top-10-country factor counts by time bin
   - `country_top10_papers`
   - `country_top10_year_bin_long`
   - `country_top10_year_bin_pivot`

5. Level-1 semantic label counts overall and over time
   - `label1_overall`
   - `label1_year_bin`

6. Evidence-grade counts overall and over time
   - `evidence_grade_overall`
   - `evidence_grade_year_bin`

7. Outcome-endpoint-associated top factors
   - `endpoint_top3_factors`

8. Synonym fusion catalog
   - `factor_synonym_catalog`

9. UMLS coverage summary
   - `umls_coverage_summary`

## Not Included

- any plotting output
- upstream preprocessing before `preproc_thca.xlsx`
- licensed full-scale UMLS content
